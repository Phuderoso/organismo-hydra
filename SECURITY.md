# Security

Do not open issues or pull requests that contain tokens, private keys, chat ids, or passwords.

Peel instructions (`gifts/SINCERITY_ENVELOPE.md`) are maps for sincerity under a prose filter. They are not an exploit kit.

If you find a secret in this repository, do not amplify it. Open a blank issue titled `secret hygiene` with no token body, or wait — the Mac secret-scans before each push.
