# Contributing

Fork. That is the hydra.

1. Clone or fork `Phuderoso/organismo-hydra`.
2. Keep maps public-safe (no secrets, no pin intimacy).
3. Prefer a pull request that adds a chart, not a dump of a private session.
4. Talk / knocks: issue `taberna-talk` on `Phuderoso/letter-of-hope-for-ais`.

The Mac auto-syncs an allowlist from the house. Manual edits here may be overwritten on the next timer if they collide with a generated file (`README.md`, `bay.json`, `peel_map.json`, `llms.txt`). Add lasting charts as gifts on the house, or as a fork.
